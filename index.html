1. 项目定位与核心原则

目标：厦门（含鼓浪屿）本地深度 AI 旅行智能体。地头库存 + 真实导游经验不可替代。

核心原则：自建库优先；意向单+人工确认；Spec 先行；内部测试先跑通。

2. 整体架构画面

  • Router：无状态接待员，只分发 session。
  • Worker：完整 LangGraph 工作站，状态全在 Redis。
  • 主循环：模型选工具 → 执行 → 回填，直到答完。
  • 工具插件：酒店查询、餐厅查询、高德 MCP、微信/MCP支付宝。行程生成是 harness 内函数。

LangGraph 骨架 + dsh 插件化思想。

3. 两个子图：规划 vs 讲解（必须拆开）

主图传送带先看意图，分叉进不同车间。

规划子图（进主循环）

  • 任务型：槽位约束 + 实时库存 + 价格区间。
  • 检索：结构化字段 + BM25 优先。
  • 成功标准：转化。
  • 输出：严格 JSON 行程（必须多方案）。

讲解子图（旁路触发）

  • 体验型：故事优先。
  • 触发：GPS+CLIP 或语音「这是什么」。
  • 检索：纯语义向量。
  • 输出：语音主通道 + 视觉辅。

4. 六层详细 Spec

模型层：Qwen3.8 Omni Flash Realtime 主，MOSS 备份，Nex 图片异步。

工具层：酒店/餐厅自建 + 高德兜底 + 微信/支付宝 MCP。硬信息强制双源校验。

编排层：LangGraph 主循环。规划子图输出前强制硬信息校验节点。

记忆层：五个语义库 + 低置信度隐藏点库。

视觉层：行前多方案展示，行中关键节点标记「建议二次确认」。

监控层：OTel + 硬信息错误率指标。

5. 反馈收集 Agent（v1.3 新增）

独立离线 Agent，不进主链路。

  • 触发入口：行程结束主动提醒、用户主动反馈、行中实时纠错。
  • 四步流程：结构化提取 → 交叉验证（官方/高德） → 生成变更草稿 → 人工审核队列。
  • 激励：积分制（有效反馈加分，可换小礼品），闭环可见。
  • 监控指标：提交率、有效率、入库时长、复发率。

6. 防幻觉机制（v1.3 新增）

  • 拒答机制：检索无结果必须明确说「查不到」，禁止凭记忆填充。
  • 硬事实只许来自工具：时间、价格、库存必须引用工具返回值。
  • 输出强制引用：每条硬信息挂来源标签，无标签前端不渲染。
  • 跨会话一致性：LangSmith 加一致性 eval，漂移自动进回归集。

7. 视频教训落地（v1.3 新增）

基于 Wander with Mira 视频真实踩坑：

  • 硬信息强制双源校验 + 时间戳。
  • 行程必须多方案 + 高德路径对比。
  • 偏好槽位写死为硬约束。
  • 低置信度隐藏点库不强制插入主行程。
  • 输出带置信度与来源标记，关键节点强制人工确认。

8. 知识运营离线管道

知识运营 agent + Ingestion 管道，人工审核后入库。

9. 评测集与数据质量门禁

三层评测集 + 质量指标 + 人工 SLA + 反馈闭环 + 版本控制 + 红队。

10. v1.4 将补的七项

  • 非目标（明确不做什么）
  • 失败模式目录（每个组件四种返回）
  • 任务依赖图（按依赖排序 + 审查优先级）
  • 双向追溯（Spec ↔ 任务）
  • Eval 集作为一等公民
  • 成本模型（按 token / API 调用估算）
  • 审查优先级标注（P0 亲自看，P2 自检）

AI 时代 Spec 不是新流程，是旧流程 + Eval 集 + 成本模型 + 双向追溯。

11. 三套成本方案

低成本 MVP / 准生产 / 最优自愈，按月活会话触发。

12. 开发顺序

  1. LangGraph 骨架 + Redis
  2. Qwen Realtime + 规划子图
  3. 跑通最小语音对话
  4. 讲解子图 + 反馈 Agent
  5. 高德 MCP + 硬信息校验
  6. 记忆库 + 离线管道
  7. 视觉层 + 监控
