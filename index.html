1. 项目定位与核心原则

目标：厦门（含鼓浪屿）本地深度 AI 旅行智能体。地头库存 + 真实导游经验不可替代。

核心原则：自建库优先；意向单+人工确认；Spec 先行；内部测试先跑通。

2. 整体架构画面

  • Router：无状态接待员，只分发 session。
  • Worker：完整 LangGraph 工作站，状态全在 Redis。
  • 主循环：模型选工具 → 执行 → 回填，直到答完。
  • 工具插件：酒店查询、餐厅查询、高德 MCP、微信/MCP支付宝。行程生成是 harness 内函数，不是独立工具。

LangGraph 骨架 + dsh 插件化思想。

3. 两个子图：规划 vs 讲解（必须拆开）

主图传送带先看意图，分叉进不同车间。两个车间各干各的，不抢机器。

规划子图（进主循环）

  • 任务型：槽位约束 + 实时库存 + 价格区间。
  • 检索：结构化字段 + BM25 优先，向量兜底。
  • 成功标准：转化（订没订、走没走）。
  • 输出：严格 JSON 行程。

讲解子图（旁路触发，不进主循环工具选择）

  • 体验型：故事优先、参数靠后。
  • 触发：GPS+CLIP 定位到 POI，或语音说「这是什么」。
  • 检索：纯 HNSW 语义向量，top-3 + 置信度。
  • 生成：像懂行本地导游讲故事，不像说明书。
  • 输出：语音主通道 + 视觉辅（手机明信片 / 眼镜 AR 锚点）。
  • 流水线：触发一次 → 检索一次 → 生成一次 → 输出一次，不循环。

路由规则写死：「帮我排三天」走规划；「这是什么房子」走讲解。不让模型自己猜。

4. 六层详细 Spec

4.1 模型层

主：Qwen3.8 Omni Flash Realtime。备份：MOSS TTS/转写。图片：Nex N2.6（异步）。视频：MOSS-VL-Realtime（云 API，第三期）。

4.2 工具层

酒店自建轻量系统 + 意向单人工确认。餐厅双库（自建优先）。行程生成是 harness 函数。高德 MCP 兜底。支付走微信/支付宝 MCP。

4.3 编排层

LangGraph + 插件规范。超时 3s + 重试 + 降级打标。状态 Redis。并发三档按日活触发。

4.4 记忆层

五个独立语义库（931栋、小吃、典故、打卡点、古早味）。统一检索插件按场景路由。规划走结构化+BM25，讲解走纯语义。混合检索 + RRF。

4.5 视觉层

行前：生成式 UI。行中：动态层（高德路网 + Leaflet + GPS+CLIP）+ 增强层（约50栋轻量锚点给眼镜 SDK）。

4.6 监控层

OTel span。开发期 LangSmith 免费层。准生产后可升级。最优终态自托管 LangFuse。

5. 知识运营离线管道（自我进化）

运行时讲解子图不负责进化。进化是后台离线线。

  • 知识运营 agent：定时网络搜索鼓浪屿新资料 → 整理成档案模板草稿 → 进人工审核队列。确认才入库，拒绝留记录。
  • Ingestion 管道：
    • 录音 → MOSS transcribe 转文字 → Nex 2.6 抽字段 → 生成草稿 → 人工队列。
    • 照片 → CLIP 图文向量 → 匹配已有档案，top-1 挂上，未命中标待归档。
  • 三者通过讲解库这个唯一交汇点连接，互不干扰。

6. 评测集与数据质量门禁

评测集（三层）

  • 回归集：生产 trace 真实问答，人工标标准答案。
  • 合成集：LLM 按模板批量生成模拟问答（各库至少 100 条）。
  • 对抗集：模糊问题、错误 GPS、冲突信息。

数据质量指标（写死）

  • 来源可追溯率 100%。
  • 置信度标注完整率 100%。
  • 核心字段填充率 ≥ 95%。
  • CLIP 相似度 > 0.95 自动合并 + 人工确认。
  • 超 1 年未更新标黄提醒补采。

人工审核 SLA

  • 草稿 24 小时内处理，超时升级。
  • 导游一级审事实，你二级审语气和优先级。
  • 动作全留日志，可回滚。

反馈闭环 + 版本控制 + 红队

  • 游客点赞/点踩（点踩必填原因）→ 进知识运营输入。
  • 每条记录带版本号，更新是追加不是覆盖，可回退。
  • 每周自动生成刀钻问题打讲解子图，失败进回归集。

8. 合规清单（内部测试可暂缓）

ICP、算法备案、大模型登记、拟人化交互合规、内容标识、等保。关门测试不对外可先不做。

9. Inventory as a Service 商业层

开放 API 层，任何模型/眼镜/应用都能调。控制「看见什么」，不控制「怎么看见」。收抽成。

10. 开发顺序

  1. LangGraph 骨架 + Redis。
  2. Qwen Realtime + 规划子图（三个核心工具）。
  3. 跑通最小语音对话。
  4. 讲解子图旁路触发。
  5. 高德 MCP 兜底。
  6. 记忆库（先 100 栋 + 踩点餐厅）+ 离线管道。
  7. 视觉层 + 监控埋点。

验收：语音首包 <800ms，端到端 P95 <2s，工具成功率 ≥99%，降级率 <5%。
